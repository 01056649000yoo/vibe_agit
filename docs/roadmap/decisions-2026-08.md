- 2026-08-31: **종료된 포인트 보상은 잔액 정합성을 위한 감사 원장에만 보존하고 현재 학생 활동 화면에서는

  폴링·Realtime을 추가하지 않는다.

  수호룡의 오늘 글이 없는 날에는 켜진 학생 모듈의 매니페스트 추천만 모아 하루 한 가지를 고정해 보여 주고 새 조회·

  책 수는 교사용 참고 통계로만 남긴다. 기준 변경으로 현재 학생의 칭호가 내려가지 않도록 적용 순간의 달성 단계를

- 2026-08-31: **학급 발자국의 과제 활동일은 승인 시각, 독서록·일기는 완료본 생성 시각을 사용한다.**
  친구 교류는 자기 글을 제외한 실제 댓글·반응 이벤트 수로 양쪽 기준을 맞춘다. 포인트는 활동 획득과
  교사 조정을 분리하고 시작 보너스도 서버 응답에서 별도 보존해, 교사 조정이 학습 활동처럼 보이지 않게 한다.

  현재·미래 학급은 전역 스위치로 열되 학급별 명시적 ON/OFF가 우선하며, 새 학급에는 첫 공용 칭호 시즌을
  자동 생성한다. 보상은 자동 지급하지 않고 학생이 직접 수령한다. 운영 이상 시 전역 OFF로 즉시 중단하고,
  공개 뒤 7일 기술 안정성과 4주 포인트 경제 관측은 계속한다.

- 2026-08-31: **칭호 시즌은 작가·소통·기록가·독서가 네 축이 하나를 공유하고, 1차 단계 포인트는 새 기록가·
  독서가에만 붙인다.** 기존 시즌 ID·마감 스냅샷을 재사용하며 새 학기에는 진행도와 수령 기회만 새로 시작하고
  글·포인트·공방 아이템은 보존한다. 시작 단계는 0P, 이미 오른 단계도 자동 지급하지 않고 학생이 직접 받는다.
  기록가·독서가 각각 2~7단계 `200/400/600/800/1,200/1,800P`, 종목별 누적 5,000P로 구성한다.
