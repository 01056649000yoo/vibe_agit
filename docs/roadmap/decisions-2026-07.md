# ROADMAP 결정 기록 보관 — 2026년 7월

> 남은 `[ ]` 는 [BACKLOG.md](BACKLOG.md) 에 모인다. 지금 할 일은 [OPEN_ITEMS](../OPEN_ITEMS.md) 에 있다.

- 2026-07-31: 학생 글쓰기의 맞춤법 지원은 **앱 내부 수첩 밑줄 + 학생 주도 `맞춤법 찾아보기`**로 한다.
  기기 안의 확정 규칙은 제목·본문에서 명확한 오류 후보만 표시하되 글을 자동 변경하거나 외부로 전송하지 않는다.
  검색은 낱말·짧은 문장을 수첩에서 직접 찾고, 학생이 찾기를 명시적으로 누른 낱말·짧은 구만 인증 서버 함수를 통해
  국립국어원 표준국어대사전에서 조회한다. 문장 전체를 외부로 보내지 않고 비용이 드는 공용 AI를 호출하지 않으며,
  OS 자동 수정도 끄고 저장·제출 코어와 분리된 `writing/tools` 슬롯으로 확장한다.

- 2026-07-30: 칭호를 제외한 글쓰기 발자국은 `writing-footprint`의 **공용 시각화 + 학생 본문 컴포넌트**로 유지한다.
  교사 화면은 같은 표현 규칙을 재사용하되 현재 학년도 학급 집계만 별도 RPC로 받고, 학생 간 등수 대신 개인별 참여·최근 기록을 표시한다.
  교사용 `학급 발자국`은 평가의 하위 화면이 아니라 아지트 놀이터 다음의 독립 상단 업무 탭으로 둔다.

- 2026-07-30: 학생 자신의 **작가·독자 칭호는 `writing/title-status` 공용 모듈만 조회·표시**한다. 나의 아지트와
  글쓰기 발자국에서 개별 레벨 계산이나 독자 점수 조회를 다시 만들지 않고, 공용 RPC·캐시·뱃지·설명판을 그대로 재사용한다.

- 2026-07-30: 친구 아지트 `최신 글`은 과제와 독서록을 한 피드에 섞지 않고 **`선생님 과제 최신글 / 독서록 최신글` 고정 탭**으로
  나눈다. 과제 탭을 기본값으로 하며 기존 과제별 필터는 그 안의 보조 탐색으로 유지한다. 두 유형은 받은 뒤 화면에서 거르지 않고
  `student_posts.class_id`와 유형 조건을 함께 건 별도 최신순 조회로 페이지를 나눈다.

- 2026-07-30: 친구 아지트는 친구의 모든 활동을 보여 주는 정보창이 아니라 **공개 자기표현과 둘 사이의 관계를 보는 공간**으로
  축소한다. 목록은 드래곤 성장치 대신 이름·작가/독자 칭호로 찾고, 상세는 칭호·반려 드래곤·공개 서재·서로의 공개 글에 남긴
  승인 댓글/반응만 표시한다. 글쓰기 전체 통계와 포인트 활동 횟수는 기존 모듈을 삭제하지 않고 친구 화면 연결만 끊는다.

- 2026-07-30: 독자 칭호 경계는 한 학기만에 중앙 학생이 상위권에 닿지 않도록, 최원진 교사의 현재 운영 학급 실데이터를
  기준으로 **`0 / 1 / 20 / 50 / 120 / 200 / 300점`**으로 재보정한다. 1점의 `첫 독자`는 즉시 성취감 때문에 유지하고,
  1년 뒤 최소 절반이 Lv5에 닿되 Lv6·Lv7은 꾸준한 학생에게 남긴다. 점수·댓글·반응은 변경하지 않고 계산 경계만 바꾼다.

- 2026-07-30: **작가 칭호가 세는 글의 정의를 한 곳으로 고정한다** — 과제글은 미션별 가장 최근 한 편,
  자율글(`mission_id IS NULL`)은 각 글을 한 편. 클라이언트는 `writerLevels.js`의 `collectWriterPosts()`,
  SQL은 `get_my_writing_footprint_detail`의 `level_posts` CTE가 짝이며 한쪽만 고치면 안 된다.
  활동 통계(달력·연속 기록·이달의 활동·가장 길게)는 중복 제거 없이 승인 글 전체를 센다 — 재작성한 날도 글을 쓴 날이다.

- 2026-07-30: **칭호 뱃지는 256px WebP로만 제공한다**(화면 최대 76px × DPR 3). 512px PNG는 40~76px 표시에
  과했고 설명판 한 번에 3.3MB를 내려받았다. `<picture>` PNG 폴백은 두지 않는다 — WebP는 2020년 이후 브라우저에서
  보편이고, 파일을 두 벌 유지하면 단계 추가 때 어긋난다. 변환은 새 의존성 없이 설치된 Edge/Chrome을
  Playwright로 띄워 쓴다(`npm run badges:optimize`).

- 2026-07-30: 후속 사용자 확인으로 바로 아래의 `축별 기본 훈장 2종 + LV` 결정을 폐기하고,
  **작가 10단계·독자 7단계 각각 다른 뱃지 이미지 17종**을 적용한다. 기본 화면에는 현재 단계 이미지만 간결하게 표시하고,
  설명판에서는 달성 이미지는 원색, 미달성 이미지는 잠금·회색 처리해 성장 방향을 미리 보여 준다.

- 2026-07-30: 나의 아지트 칭호 이미지는 단계마다 17종을 따로 만드는 계획 대신 **작가/독자 축별 훈장 2종 + 현재 LV 표식**으로 바꾼다.
  기본 화면은 두 뱃지와 현재 이름만 간결하게 보여 주고, 성장 공식·전체 단계·다음 조건은 뱃지를 눌러 여는 설명판으로 이동한다.

  공통 셸이 학급 ON/OFF와 카드·로딩·오류를 담당하고, 모듈은 교사 관리(`teacherEntry`)와 학생 실행(`studentEntry`) 및
  전용 데이터만 소유한다. 신규 모듈은 열 때만 조회하며 OFF는 데이터를 지우지 않는다. 기존 드래곤·어휘탑은 회귀를 막기 위해
  우선 `game/legacy` 호환 어댑터로 격리하고, 기능별 실기기 검증 후 각 모듈의 `teacherEntry`로 옮긴다.

  성취기준은 개별 학년이 아니라 교육과정 단위인 **3~4학년군 / 5~6학년군**으로 선택·저장하며, 기존 `grade` 값은 읽을 때
  학년군으로 변환하고 다음 저장부터 `grade_band`를 사용한다. 직전 국어·사회·과학 확장 계획은 이 결정으로 철회한다.

- 2026-07-29: **글쓰기 자체를 독립 평가 영역으로 취급하지 않는다.** 학생 평가에는 국어 활동에서 나온 글과 실제 평가 결과·교사 관찰을
  근거로 남기고, 평어 도우미에서 교사가 평가계획에 맞는 국어 성취기준을 직접 확정한 뒤
  그 근거로 앞뒤 문장에 자연스럽게 이어 붙일 짧은 평어 문장을 생성한다. AI의 성취기준 자동 추정은 추천에만 사용하고
  최종 선택은 교사가 하며, 결과 화면은 학생마다 문장을 바로 복사할 수 있게 한다.

  최근 활동은 과제·독서록·댓글의 실제 시간순 피드만 담당한다. 댓글 피드는 글쓰기 발자국 도입 이후 이벤트가 아니라
  `post_comments`의 승인된 학급 댓글 원본을 사용해 기존 댓글도 보여 주되, 목록은 미리보기만 반환하고 전문은 선택 시 조회한다.

- 2026-07-29: 학급 운영 현황은 학생 순위를 강조하지 않고 **기간별 학급 활동 + 교사가 지금 확인할 일 + 미션별 진행 상태**로 구성한다.
  수시 집계가 필요한 교사 화면은 원천 목록을 내려받지 않고 전용 RPC로 계산하며, 고쳐쓰기·댓글·피드백은 글쓰기 발자국 도입 이후 자료만 사용한다.
  마감일 데이터가 아직 없으므로 `지각/기한 초과`로 표현하지 않고 **현재 미제출**로만 표시한다.

  본문은 선택 시 한 건만 조회한다. 학생에게는 자기 독서록의 `확인했어요` 또는 교사 한마디만 보여준다.

- 2026-07-27: 글쓰기 발자국과 피드백 횟수는 **기능 도입 이후 자료부터** 기록한다. 기존 댓글 중복 자료는 삭제하지 않고
  통계에서 `DISTINCT`로 완화한다. 끄적끄적 아지트 헬퍼 통합은 친구 정보창과 글쓰기 구조가 안정된 마지막에 RPC 데이터 연동으로 진행한다.

- 2026-07-27: **권한 회수는 `PUBLIC` 과 역할 양쪽 모두에서 해야 한다.** `FROM anon` 만 회수해도 PUBLIC 권한이
