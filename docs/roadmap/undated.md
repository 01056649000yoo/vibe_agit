### 맥미니 전체 장애 점검 안내 이중화 (2026–27 겨울방학 예정)

- [ ] 맥미니 전원·호스트 Caddy·가정 인터넷이 모두 불능이어도 **평소 서비스 주소**에서 점검 화면이
      자동으로 나오도록 외부 장애 안내 계층을 설계한다.
- [ ] 우선안은 `Cloudflare Worker → 맥미니 Caddy 원본`으로 둔다. 앱과 정적 파일의 실제 호스팅은
      계속 Caddy가 담당하고, Worker는 원본 연결 오류·`502/503/504` 때만 정적 점검 화면을 반환한다.
- [ ] 적용 전 가비아 DNS 전체 백업, 원본 전용 호스트의 재귀 호출 방지·접근 보호, 무료 한도 대비 실제 요청량,
      `api.`·`helper.`·Google OAuth 영향 범위를 확인하고 시험용 하위 도메인에서 장애·복구 리허설을 한다.
- [ ] 겨울방학 적용 전까지는 현재 Caddy 내부 점검 화면만 유지한다. 따라서 맥미니 또는 인터넷 전체 장애 때는
      점검 화면 대신 브라우저 연결 오류가 보이는 현재 한계를 운영상 수용한다.
