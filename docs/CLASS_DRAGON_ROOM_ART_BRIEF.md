# 우리 반 드래곤 교실 — GPT 그림 의뢰서

> 계획: [CLASS_DRAGON_ROOM_PLAN.md](CLASS_DRAGON_ROOM_PLAN.md). 만드는 사람: 선생님(ChatGPT 이미지 생성). 이 파일은 **프롬프트 틀과 파일 규칙**이다.

## 1. 공통 규칙
- 같은 **화풍·색·선 굵기**로 모든 그림을 만든다. **기존 드래곤 그림을 참고 이미지로 첨부**한다(`public/assets/dragons/v2/{종류}/level-{단계}.webp`).
- 캔버스 **정사각형 768×768**, **배경 투명(PNG)** → 변환해 webp로 넣는다(장당 ~40KB 이하 권장).
- 드래곤 + 책상 + 의자를 **한 그림**으로(책상은 어두운 갈색 나무 책상, 의자는 같은 색, 앞쪽에 비어 있는 이름표 자리). 코드가 이름표·문패·테두리를 위에 올린다.
- 시점은 **정면에서 살짝 위(3/4 정면)**, 드래곤은 **정면을 보고 앉는다**. 모든 그림에서 책상 크기와 위치가 같아야 한다.
- 그림 안에 **글자·로고·워터마크를 넣지 않는다.**
- 아래 40장은 종류별로 이어서 만든다(한 종류 10장 → 다음 종류).

## 2. 앉은 드래곤 40장
경로: `public/assets/dragons/desk/{종류}/level-{단계}.webp`  종류: `star`(별빛룡·파랑) `forest`(숲수호룡·초록) `ember`(노을룡·주황/붉은색) `moon`(달빛룡·보라)

**프롬프트 틀(성체, 단계 3~10):**
> 첨부한 드래곤과 **같은 캐릭터**가 초등학교 교실의 작은 나무 책상 앞에 의자에 앉아 **정면을 보고 있는** 모습. 책상 위에는 펼친 공책과 연필이 놓여 있다. 정면 3/4 시점, 귀엽고 따뜻한 일러스트 화풍, **배경 투명**, 정사각형 768×768, 글자 없음. 드래곤 크기는 **단계 {n}/10**에 맞게(1에 가까울수록 작고, 10에 가까울수록 크고 위엄 있게). 책상과 의자는 모든 그림에서 같은 크기·위치.

**알 단계(1~2단계):**
> 첨부한 알과 **같은 알**이 책상 위 작은 쿠션에 놓여 있다. 나머지는 위와 같은 규칙.

단계 설명(기존 규칙): 1~2 알, 3 부화한 새끼, 4~6 성장, 7~9 성체, 10 최종(반짝임 허용).

## 3. 교실 배경 1장
경로: `public/assets/class-room/classroom-day.webp`  크기 **1600×900(16:9)**, 불투명.
> 초등학교 교실을 정면에서 본 일러스트. 위쪽 중앙에 **비어 있는 초록 칠판**(글자 없음, 나중에 코드가 글씨를 올림), 양쪽에 창문, 아래쪽은 **빈 나무 바닥**(책상 없음, 학생 없음, 가구 최소). 따뜻한 낮 조명, 위 드래곤 그림과 같은 화풍.

(선택) 저녁 버전 `classroom-evening.webp`: 같은 구도에서 조명만 노을빛.

## 4. 받으면 제가 하는 일
- 파일을 위 경로에 넣으면 코드 변경 없이 교실에 나타난다(없는 그림은 기존 서 있는 그림 + 코드 책상으로 대체).
- 크기·투명도·비율이 안 맞는 그림은 목록으로 알려 드린다.
