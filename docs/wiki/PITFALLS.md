> 넣을 갈래가 없으면 갈래를 새로 만든다 — 아무 데나 붙이면 한 갈래가 쓰레기통이 된다.

## 배포·운영

- **정적 서버의 SPA 폴백은 `/assets/` 에 걸면 안 된다.** 사라진 옛 조각에 index.html 을 immutable 로 돌려줘
  배포 직후 열린 탭이 `Importing a module script failed` 로 죽었다. Caddy `try_files` 는 조건을 받지 않으니(검증은 통과한다)
  실제 컨테이너로 요청해 확인한다. (2026-09-23)
- **마이그레이션을 앱보다 먼저 적용한다.** 순서가 바뀌면 화면에는 기능이 보이는데 저장이 거절된다.
  `npm run migrate` → 배포. (2026-09-02)
- **시크릿을 넣은 뒤 `docker restart` 로 끝내지 않는다.** 엣지 함수는 `docker-compose.agit.yml` 의
  `env_file` 로 값을 받는데 이건 **컨테이너를 만들 때만** 읽힌다. `up -d --force-recreate --no-deps functions`
  로 다시 만들고(`--dry-run` 먼저), `docker inspect` 로 이름만 확인한다. (2026-09-17)
- **맥미니에 마이그레이션을 직접 보낼 땐 `git show HEAD:<경로>` 로 보낸다.** 체크섬은 파일 바이트라
  작업본이 CRLF 면 저장본(LF)과 원장이 어긋난다. `*.sql` 은 `.gitattributes` 로 LF 고정. (2026-09-14)
- **이 앱의 주소는 `끄적끄적아지트.site`(xn--vz0ba242ncqcba79xhwx) 다.** `끄적끄적.kr` 은 샘링크,
  `app.끄적끄적.kr` 은 자비스다 — 셋 다 같은 맥미니라 아무 주소나 200 이 돌아온다. 2026-09-13 에
  엉뚱한 주소로 "운영 정상" 이라 보고했다. 배포 확인은 `agit-app` 컨테이너의 `/srv/assets` 를 직접 본다.

## DB·권한

- **`SECURITY DEFINER` 를 anon 에 열지 않는다** — RLS 를 우회한다. "내부 전용"이라 적힌
  `notification_emit_v1` 이 PUBLIC 에 열려 있었다(2026-09-09). 이제 `check:rpc-surface` 가 막는다.
- **`authenticator` 역할에는 `safeupdate` 가 preload 돼 있다.** 함수 안에 WHERE 없는 DELETE/UPDATE 를 두면
  psql(`postgres` 역할)에서는 통과하고 **앱에서만** `DELETE requires a WHERE clause` 로 400이 난다.
  2026-09-06에 `manage_class_agit_rollout_v1` 이 이 때문에 처음부터 저장이 안 됐다(`61241`→`61253`).
  `tests/sqlSafeUpdate.test.mjs` 가 이제 막는다. RPC 를 손으로 확인할 때는 `authenticator` 로 붙어 본다.
- **원글/편집 충돌에 SQLSTATE `40001`을 쓰지 않는다.** PostgREST 14.12가 끝없이 재시도해 응답이 안 끝난다(2026-09-05). 새 입력이 필요한 충돌은 `PT409` 로 쓰고 HTTP 409까지 검사한다.
- **전시 발행의 잠금은 원글 회수와 함께 시험한다.** 부모·전시를 잠근 뒤 원글을 기다리면 회수 트리거와 교착할 수 있다. 발행 잠금은 NOWAIT/짧은 상한과 `PT409`로 끝내고 동시 HTTP 검사로 확인한다. (2026-09-05, `61243`)
- **스모크의 `LIMIT 1`은 원하는 상태를 먼저 좁힌다.** 같은 시각·무작위 UUID 행 중 하나를 뽑으면 한 번은
  통과하고 다음에는 이미 처리한 행을 골라 실패한다. (2026-09-04)

## 화면 그리기

- **화면을 바꿨으면 배포 전에 실제로 렌더링해 본다.** `?dev-lab=<시나리오>` 로 DB 없이 띄운다.
  눈으로 안 보고 넘긴 날 두 번 다 사용자가 먼저 발견했다. 손으로 만든 HTML 로 재면 틀린 수치를 읽는다.
  dev-lab 은 `import.meta.env.DEV` 라 **개발 서버에서만** 뜬다(`vite preview` 로는 안 된다). (2026-09-02)
- **겹침·정렬 같은 그림 문제는 눈이 아니라 좌표로 검사한다.** 자리 계산을 `.jsx` 밖 `.js` 로 꺼내면
  `node --test` 가 직접 부를 수 있다. 그렇게 만든 검사가 눈으로 못 본 버그 둘을 바로 잡았다.
  (이때 import 에 **확장자를 적는다** — Vite 는 없어도 찾지만 Node 는 못 찾는다.) (2026-09-03)
- **그림 위에 글자를 얹기 전에 그 자리에 무엇이 오는지 본다.** 트랙의 `출발`·`목표` 를 선 위에 뒀더니
  위로 어긋난 점과 겹쳤다. 겹치는 축을 피해 선 양옆으로 옮기면 자리도 덜 먹는다. (2026-09-03)
- **고치려던 문제를 새 부품이 그대로 되풀이하지 않는지 그려 보고 확인한다.** "브라우저 기본 창은
  긴 이름이 잘린다"를 이유로 앱 안 창으로 옮겨 놓고, 새 창 제목이 `white-space: nowrap` 이라
  똑같이 잘렸다. 코드만 읽었으면 못 봤다. (2026-09-03)

## 브라우저가 말없이 다르게 굴 때

- **`window.confirm` 은 크롬이 막으면 조용히 거짓을 돌려준다.** "추가 대화상자를 표시하지 않음"이
  켜지면 창이 아예 안 뜨고 코드는 "취소를 눌렀다"고 판단해, 버튼을 눌러도 아무 일이 없다.
  사람은 원인을 알 길이 없다. 새 흐름에는 `useConfirmDialog` 를 쓴다. (2026-09-03)
- **native dialog도 Tab 끝·Shift+Tab 시작을 직접 검사한다.** 내장 브라우저에서 초점이 문서 밖으로 빠졌다.
  처음/마지막 컨트롤을 직접 순환시키고, 액자 초점 복귀는 dialog 가 닫힌 뒤에 한다. (2026-09-05)
- **로그인 세션은 localStorage 가 아니라 쿠키(`sb-agit-auth-token`)에 있다.** `localStorage.clear()` 로는
  안 지워지고, `@supabase/ssr` 은 조각(`.0`,`.1`)으로 나눠 담아 하나만 남아도 옛 토큰이 되살아난다.
  계정이 지워진 뒤엔 서버 로그아웃도 실패한다 — `clearStoredAuthSession()` 로 이름·조각까지 지운다. (2026-09-13)

## 크기를 재서 그릴 때 (화면이 떨리면 여기부터)

- **잰 크기를 상태에 넣을 때는 값으로 견준다.** 잴 때마다 새 객체를 넣으면 값이 같아도 React 가
  그 아래를 통째로 다시 그린다. 확대·축소 중에는 `getBoundingClientRect()` 가 소수를 주고 미세하게
  흔들려서, 재기 → 다시 그리기 → 또 재기 로 이어져 **화면이 떤다**(우리학급 스크린, 2026-09-21).
  재는 값을 **정수로 끊고**, 같으면 상태를 갈아 끼우지 않는다.
- **자기가 크기를 바꾸는 요소를 자기가 `ResizeObserver` 로 감시하지 않는다.** 글씨를 키움 → 내용
  넘침 → **스크롤 막대가 생겨 안쪽 폭이 줄어듦** → "크기 바뀜" 알림 → 다시 맞춤 → 막대 사라짐 → …
  으로 고리가 닫힌다. 막는 법은 둘 — 재는 동안 넘침을 숨기고, **바깥 상자(offset)** 가 실제로
  달라졌을 때만 다시 맞춘다. 안쪽(client)을 견주면 막대 때문에 생긴 변화를 못 걸러낸다.
  맞춤 원본은 `widgets/useFittedWidgetBox.js` 하나뿐이다 — 베끼면 차단기를 빠뜨린다.

## 고칠 때 함께 볼 것

- **훅은 이른 `return` 보다 위에 둔다.** `useMemo` 를 `if (loading) return ...` 아래에 넣었더니
  렌더마다 훅 순서가 달라졌다(`react-hooks/rules-of-hooks`). **빌드는 통과했다** — 배포 빌드는 lint 를
  돌리지 않는다. 2026-09-17 부터 푸시 전 검사가 막지만, 훅을 안 깐 기기에서는 그대로 나간다. (2026-09-03)
- **화면을 고쳤으면 도움말도 같은 커밋에서 고친다.** 기능을 처음 만들 때만 적고 그 뒤 세 번 고치는 동안
  도움말을 안 건드려, 하루 만에 실제 화면과 어긋났다(`teacherGuides.js`·운영 문서 세 곳). (2026-09-03)
- **한 화면이 틀렸으면 같은 숫자를 쓰는 다른 화면도 본다.** 개인전 제보였는데 모둠 대항전·현황 창도
  같은 원인으로 틀려 있었다. (2026-09-03)

## 판단·확인

- **원인을 추정으로 단정하지 않는다.** "배포가 검사기 이미지를 지웠다"고 기록했다가 확인해 보니
  그 단계는 빌드 캐시만 지웠다. 모르면 **모른다고 적는다.** (2026-09-02)
- **새로 넣은 검사는 일부러 망가뜨려 실패하는 것까지 본다.** 통과만 하고 아무것도 안 보는 검사가
  여러 번 나왔다(정규식이 `window.confirm` 을 놓침, 같은 계산이 두 곳인데 한 곳만 봄). `${…}` 문구는 백틱인지도 본다.
- **미리보기가 상태를 손으로 흉내 내면 거짓 통과가 난다.** 동행 모드 다시 보기를 두 번 헛짚었다 —
  흉내는 잘 도는데 본 코드는 아니었다(2026-09-13). 상태 훅을 쓰는 화면은 **그 훅 그대로** 미리 본다.
- **증상이 "언제" 나는지부터 묻는다.** 스크린 떨림 제보를 그럴듯한 기전(글씨 자동 맞춤 고리)으로
  단정해 엉뚱한 곳을 고쳐 배포했다(2026-09-21). "확대·축소할 때"라는 한마디가 나오고서야 범위가
  좁혀졌다. 눈으로만 보이는 고장은 **재현 조건을 먼저 받아 적는다** — 고치기 전에.
- **셸 heredoc 안에서 정규식을 쓰면 `\b` 가 진짜 백스페이스 문자(0x08)로 박힌다.** 검사는 통과하는데
  아무것도 잡지 못하고, `grep` 으로 보면 멀쩡해 보인다. 정규식을 파일에 쓸 땐 Edit 도구를 쓰거나
  `String.fromCharCode(92)` 로 역슬래시를 직접 넣는다. (2026-09-03)

## 바깥 것을 읽을 때

- **외부 API 는 이름만 믿지 말고 한 번 찔러 본다.** "국회도서관 키"로 받은 값이 실제로는 국립중앙도서관
  키였다(2026-09-17). 국회도서관 쪽은 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` 를 준다. 국립중앙도서관
  소장자료 검색은 **한글 검색어가 전달되지 않는다** — ISBN 조회에만 쓴다.
- **공유기 포트는 바깥 번호로 본다.** 22번이 열렸는지만 확인하고 "닫혀 있다"고 읽었는데, 실제 규칙은
  **외부 10022 → 내부 22** 였다. 안쪽 번호와 바깥 번호는 다를 수 있다. (2026-09-03)
- **`docker stats` 의 NET I/O 는 트래픽이 아니다.** 도커 내부 네트워크까지 포함해서 `agit-rest`↔`agit-db`
  대화가 실제 바깥 트래픽의 30만 배로 잡힌다(2026-09-06). 바깥 사용량은 리버스 프록시(`jarvis-caddy`) 하나만 센다.
- **취약점 검사기는 라이브러리가 있는지만 본다.** 그 코드가 실행되는지는 사람이 확인해야 한다.
  판단을 남길 때는 근거와 **유효기간**을 함께 적는다(`src/constants/serviceFindingNotes.js`). (2026-09-02)
