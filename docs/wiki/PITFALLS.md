## 배포·운영

- **마이그레이션을 앱보다 먼저 적용한다.** 순서가 바뀌면 화면에는 기능이 보이는데 저장이 거절된다.
  `npm run migrate` → 배포. (2026-09-02)
- **도커의 한도는 맥 디스크가 아니다.** 데이터는 외장 SSD 위 `Docker.raw`(상한 32GB) 안에 있다.
  맥이 93GB 남아도 도커는 찰 수 있다. 관문·정리는 `scripts/trim-docker-cache.sh` 가 도커 안쪽을 본다. (2026-09-02)
- **실행 이미지에서 도구를 지우기 전에 실행 명령부터 본다.** 단축링크는 `npm run start` 가 실행 손잡이라
  npm 을 먼저 지우면 컨테이너가 시작조차 못 했다. (2026-09-02)
- **연구소(`writing-helper`)는 만지기 전에 `git fetch`.** 로컬이 74커밋 뒤처진 채 고쳤다가 푸시가 거부됐다. (2026-08-27)

## 판단·확인

- **확인 명령이 빈 결과를 주면 "없음"이 아니라 "확인 실패"부터 의심한다.** 권한이 없어 조용히 실패한
  포트 점검 결과를 "외부 포트 없음"으로 읽었다가, 실제로는 SSH 가 열려 있었다. (2026-09-02)
- **원인을 추정으로 단정하지 않는다.** "배포가 검사기 이미지를 지웠다"고 기록했다가 확인해 보니
  그 단계는 빌드 캐시만 지웠다. 모르면 **모른다고 적는다.** (2026-09-02)
- **취약점 검사기는 라이브러리가 있는지만 본다.** 그 코드가 실행되는지는 사람이 확인해야 한다.
  판단을 남길 때는 근거와 **유효기간**을 함께 적는다(`src/constants/serviceFindingNotes.js`). (2026-09-02)
- **새로 넣은 검사는 일부러 망가뜨려 실패하는 것까지 본다.** 통과만 하고 아무것도 안 보는 검사가 실제로 나왔다.

## 화면

- **백지로 두면 아무도 채우지 않는다.** 제보 창이 백지라 교사 203명 중 제보가 0건이었다.
  목록형 기능은 기본값을 담아 줄 길을 함께 만든다. (2026-08-21 / 2026-09-02)
- **좁은 칸에 조작 아이콘을 늘어놓으면 정작 내용이 안 보인다.** 글 상세 사이드바는 380px 이라
  아이콘 넷이면 문장 폭이 4분의 3으로 줄었다. 평소에는 내용만, 조작은 모드를 나눠 꺼낸다. (2026-09-02)
- **화면을 바꿨으면 배포 전에 실제로 렌더링해 본다.** `?dev-lab=<시나리오>` 로 DB 없이 띄운다.
  눈으로 안 보고 넘긴 날 두 번 다 사용자가 먼저 발견했다. (2026-09-02)
