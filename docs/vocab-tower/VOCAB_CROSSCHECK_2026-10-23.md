# 3~6학년 어휘 자료 교차 점검 (2026-10-23)

어휘의 탑·퀴즈 아레나가 함께 쓰는 `public/data/grade3~6_vocab.json`(1,586행)의 **뜻풀이·예문**을 GPT(Codex `gpt-6.1-sol`)·제미나이(아르곤)·클로드 세 모델이 번갈아 점검했다.
낱말·분류·난이도(덱 구성과 학생 진도 키)는 **바꾸지 않았다**. 뜻풀이와 예문 글만 고쳤다.

## 방법
1. **회전 검토** — 자료를 셋으로 나누고 세 모델이 각자 다른 몫부터 시작해 서로 바꿔 가며, 모두가 전체를 한 번씩 봤다(뜻오류·뜻어색·예문오류·예문어색·맞춤법·모호·난이도·분류·부적절). 449개 낱말에 지적이 모였다.
2. **고침안 투표** — 고칠 글이 제안된 445건(뜻풀이 311 · 예문 134)을 GPT와 제미나이가 서로의 제안을 모르는 상태로 다시 골랐다(원본 유지·A·B). **서로 다른 두 모델이 지지한 378건**만 후보로 삼았다.
3. **클로드 배심** — 후보 378건을 클로드가 전부 읽고 **25건을 되돌렸다**: 초등 눈높이에 어려워지거나(도시·세균·공식적·평행·용액), 낱말 핵심 정보를 잃거나(대물·접안·표본이 렌즈·표본 뜻을 잃음, 예보가 '날씨'를 잃음), 비슷한 낱말과 구별이 흐려지거나(토론), 아직 틀린 표기를 담은 것(국야·삼삼 제도는 낱말 자체 문제).
4. **자동 진단 신호 해소** — `scripts/audit-vocab-tower-v2.mjs` 의 `뜻에 정답 낱말 포함` 12→2건, `예문에 목표 낱말 없음` 4→1건. 클로드가 직접 고친 글 29건 포함.
5. **기본 세트 점검에서 나온 오류 반영** — 문제를 답을 가리고 풀게 하고(GPT·제미나이 전체, 클로드 표본 358문제), 정답을 보여 주고 글 오류를 물어(품질 검토) 나온 객관적 오류(`차길`→`찻길`, `201x년`→`2015년`, `한 쪽`→`한쪽`, `잘 되어`→`잘되어`, `표값`→`푯값` 등 20건)를 고쳤다.

## 결과
- 고친 낱말 **358개**(뜻풀이 또는 예문). 문서 `V2_WORD_AUDIT.md`·덱 계획·검수 후보 파일은 자동 진단을 다시 돌려 갱신했다(사람 확인이 필요한 우선 항목 28 → 17, 확인 완료 덱 20 → 27).
- **학생에게 보이는 곳**: 어휘의 탑 화면(`/data/*.json`)은 앱 배포 때 바뀐다. 서버 단어 은행(`vocab_tower_words`)은 **마이그레이션 초안** `supabase/migration-drafts/vocab_tower_words_text_fix.sql`(358낱말, 운영 DB 안에서 롤백되는 실행으로 검증) 을 선생님이 `적용해` 라고 한 뒤 `supabase/migrations/` 로 옮겨 적용한다. 서버는 낱말 존재 여부로 채점하므로 적용 전에도 학생 채점은 그대로 정상이다.

## 아직 남은 것(결정·후속)

| 낱말 표기 오류 | 6학년 `국야` → `극야`(오타), `삼삼 제도` → `삼권 분립`(잘못된 낱말이며 `권력 분립`이 이미 따로 있음). 낱말 키가 학생 진도·덱에 얽혀 있어 **바꾸지 않았다**. 기본 세트에서는 제외했다. 바로잡으려면 DB 단어 은행·덱 계획을 함께 고쳐야 한다. |
