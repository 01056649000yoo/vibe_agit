## 점검할 때 지킬 것

- 비밀 값·공인 IP·학생 이름 같은 사용자 데이터는 쓰지 않는다. 값이 아니라 **있는지·길이·위치**만 적는다.
- 항목마다 **어떻게 확인했는지**(명령·호출)와 **결과**를 함께 적는다. "안전해 보임" 으로 끝내지 않는다.
- 고친 것은 되돌아가지 않게 **검사**로 남기고(예: `tests/securityAudit20260924.test.mjs`), 그 검사가
  옛 코드에서 실패하는 것까지 본다.
- 운영 설정(인증 서버·비밀 값·게이트웨이)은 로그인에 바로 영향을 주므로 **선생님 확인 뒤** 바꾼다.
  보고서의 `결정 필요` 에 올리고, 바꾼 뒤에는 WORKLOG 에 git 밖 변경으로 남긴다.
- 설계 원칙과 계속 지킬 규칙은 [SECURITY_HARNESS.md](../../SECURITY_HARNESS.md) 가 정본이다. 이 폴더는 **그날의 기록**이다.
