## 결론

**SQL 인젝션·XSS·SSRF·오픈 리다이렉트·파일 업로드 경로는 찾지 못했다.** DB 함수에 동적 SQL이 없고,
화면은 React 이스케이프와 인라인 스크립트를 막는 CSP 로 이중 방어되며, 외부 요청 주소는 모두 코드에 고정돼 있다.

고칠 것이 나왔고 모두 고쳐 운영에 반영했다. 운영 설정을 바꿔야 하는 4건은 아래 `결정 필요` 에 올렸다.

### 3. 시간 및 상태

- 경쟁 조건: 댓글 요청 횟수는 학생별 `pg_advisory_xact_lock` 으로 한 줄로 센다. AI 검사 슬롯은 `FOR UPDATE SKIP LOCKED`.
- 끝나지 않는 반복: AI 대기열 비우기는 60건·90초 상한, 교사 폴링은 완료 기준 12초·실패 시 30~120초 후퇴.
