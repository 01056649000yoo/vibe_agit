> 관리자 `공지사항`에 아래 글을 올린다. 적용(20261409)·앱 배포 **뒤에** 올린다.

**제목**: 어휘의 탑·수호룡의 인형뽑기가 모든 학급에서 기본으로 켜졌어요

**본문**

선생님, 안녕하세요. 아지트 놀이터의 두 놀이를 많은 학급에서 쓰실 수 있도록 **기본으로 켰어요.**

- 🏰 **어휘의 탑**: 3~6학년 어휘를 풀며 탑을 오르고 포인트를 모아요.
- 🧸 **수호룡의 인형뽑기**: 수호룡이 내는 맞춤법 문제를 맞히면 코인을 받고, 코인으로 인형뽑기를 해서 포인트나 수호룡 아이템을 받아요. (선생님 선물은 처음엔 없어요. 필요하면 설정에서 더하세요.)

**학생은 하고 싶은 친구만** 해요. 모든 학생이 해야 하는 활동은 아닙니다.

**쓰지 않으실 학급은 끄세요.** 선생님 화면 → 아지트 놀이터 → 해당 놀이를 열고 위쪽 스위치를 `사용 안 함`으로 바꾸면 학생 화면에서 바로 사라져요. 기록은 보관돼요.

이미 어휘의 탑이나 인형뽑기를 쓰다가 일부러 꺼 두신 학급은 그대로예요. 포인트·코인 규칙은 바꾸지 않았어요(어휘의 탑 층당 보상 기본 100P).
