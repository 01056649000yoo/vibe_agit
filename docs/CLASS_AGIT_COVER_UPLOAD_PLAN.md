# 글꽃 책방 — 선생님이 만든 표지 그림 올리기 (계획, 2026-10-05)

> 상태: **만듦(2026-10-06, v1.25, `20261369` 운영 DB 적용)** — 화면 배포는 선생님 확인 뒤. 실제 저장소·권한·화면·인쇄 점검 결과는 WORKLOG 2026-10-06. 아래는 처음 계획(만들며 바뀐 것: 속지 ③ 쪽 번호는 동그라미 대신 굵게).

## 1. 목표와 결정

선생님이 캔바 같은 곳에서 문집 표지를 직접 만들어 **정해진 규격(비율·크기·형식)에 맞는 그림을 올리면 그 그림이 표지가 된다.** 규격이 맞지 않으면 바뀌지 않는다.

선생님 결정(2026-10-05):

| 질문 | 결정 |
| --- | --- |
| 그림이 표지를 어떻게 바꾸나 | **그림이 곧 표지 전체**. 아지트는 위에 글자를 얹지 않는다(제목은 화면 읽기 프로그램·대체 글로만) |
| 누구에게 보이나 | **문집이 보이는 곳 어디든**(우리 반 서가·모두의 아지트 문집 도서관·인쇄·구글 문서). 올릴 때 "학생 얼굴·이름이 드러난 사진은 넣지 마세요" 안내 |
| 만들기 도움 | 종이별 **빈 틀 그림(안전 영역 점선) 내려받기** |

지금 상태(2026-10-05): 문집 24권, 기본 디자인 `botanical` 15권(63%). 표지는 디자인 8종 × 종이 3종에서 고르고 글만 적는다.

### 바뀌는 범위 (2026-10-06 선생님 결정)

**맨 앞 표지 한 쪽만** 그림으로 바뀐다. 여는 글·목차(차례, 자동 쪽수)·주제 간지·작품 쪽은 지금처럼 아지트가 만든다 —
인쇄(`print.js`)·학생 화면 차례(`StudentBookReader`)·구글 문서 목차 모두 같다.

| 선생님이 고른 것 | 표지 | 목차·여는 글·간지·작품 쪽 |
| --- | --- | --- |
| 디자인만 (지금 방식) | 그 디자인 | 그 디자인 색 — 지금 그대로 |
| 그림 표지 올림 | 올린 그림 | **속지 스타일 3가지 중 하나**(처음 값 ① 단정한) |

속지 스타일(선생님 제안 "3가지 정도"):

| id | 이름 | 제목·글씨 | 선·쪽 번호 | 어울리는 표지 |
| --- | --- | --- | --- | --- |
| `plain` | ① 단정한(기본) | 검정 제목·본문 | 회색 가는 선, 숫자만 | 어떤 표지든·사진/그림이 화려할 때 |
| `warm` | ② 따뜻한 | 진갈색 제목 | 주황빛 점선, 쪽 번호 양옆 짧은 선 | 손그림·수채화 |
| `fresh` | ③ 산뜻한 | 남색 제목 | 하늘색 굵은 선, 쪽 번호 굵게 | 깔끔한 디자인·캔바 템플릿 |

- **세 가지 모두 바탕은 흰 종이** — 속지 바탕색은 쪽마다 잉크가 들고 학교 프린터에서 얼룩진다. 차이는 제목 색·선·쪽 번호로만.
- 그림을 올리면 디자인 8종 칸 대신 속지 스타일 3가지가 **목차 한 장 모양 미리보기**와 함께 나온다. `기본 디자인으로 돌아가기` 를 누르면 표지·속지 모두 고른 디자인으로.
- 지금은 표지와 속지가 같은 디자인 스타일을 쓴다(`print.js` 의 속지 제목·구분선 색이 디자인 accent). 그림 표지일 때만 속지를 떼어 낸다.
- 속지 스타일 정의는 `designs.js` 에 `BOOK_INNER_STYLES` 하나로 두고 인쇄·화면·구글 문서가 같이 쓴다. DB 는 `cover_image` 안의 `inner_style`(허용값 3개만, 서버가 확인).

## 2. 규격

| 종이 | 비율(가로×세로 mm) | 권장(300dpi) | 최소(150dpi) |
| --- | --- | --- | --- |
| A4 | 210×297 | 2480×3508 px | 1240×1754 px |
| A5 | 148×210 | 1748×2480 px | 874×1240 px |
| B5 | 182×257 | 2150×3035 px | 1075×1518 px |

- 형식 **JPG·PNG**, **5MB 이하**. (WebP·HEIC 는 인쇄·구글 문서 호환 때문에 받지 않는다)
- 비율 허용 오차 **±1%**. 최소보다 작으면 거절, 최소~권장 사이면 "인쇄하면 흐릿할 수 있어요" 경고 후 받음.
- **안전 영역**: 가장자리 5mm 안쪽에 글자. 빈 틀 그림에 점선으로 표시.
- 규격 숫자는 `designs.js` 의 `BOOK_PAPERS` 에서 계산한다(종이 표를 두 곳에 적지 않는다).

## 3. 선생님 흐름

1. `글꽃 책방` → 문집 → `표지` 단계의 디자인 고르기 아래에 **`내가 만든 표지 그림 쓰기`** 칸.
2. 종이별 규격 표 + `빈 틀 그림 내려받기(A4/A5/B5)` + 안내 한 줄(얼굴·이름 사진 금지, 저작권 있는 그림 주의).
3. 그림을 고르면 **브라우저에서 바로 검사**(형식·용량·픽셀·비율) → 틀리면 무엇이 틀렸는지 문장으로("A4는 210:297 비율이어야 해요. 지금 그림은 1:1이에요").
4. 통과하면 미리보기 → `이 그림으로 표지 바꾸기` → 저장. `기본 디자인으로 돌아가기` 단추.
5. 종이 크기를 바꾸면 비율이 안 맞으니 **올린 표지를 끄고 기본 디자인으로** 돌아가며 다시 올리라고 안내.
6. 확정판(edition)은 그때 표지를 그대로 간직한다 — 새 그림을 올려도 옛 판은 안 바뀐다.

## 4. 저장과 권한

- **저장소**: 새 비공개 버킷 `class-agit-covers`(파일 한도 5MB, `image/jpeg`·`image/png` 만). 경로 `<class_id>/<book_id>/<업로드 시각>-<무작위>.jpg|png` — **덮어쓰지 않는다**(옛 확정판이 옛 파일을 가리킴).
- **DB**: `class_agit_books.cover_image jsonb` 하나 — `{ path, width, height, mime, bytes, paper, uploaded_at }`. 없으면 지금처럼 디자인 표지.
  확정판 `snapshot` 에도 같은 값을 복사(발행 때 고정).
- **쓰기**: 기존 `run_class_agit_book_action_v1` 에 `set_cover_image` · `clear_cover_image` 동작 추가(새 판을 만들면 옛 판 삭제 규칙). 서버가 다시 확인: 담당 교사, 경로가 그 학급·문집 폴더, mime·크기, `paper` 가 문집 종이와 같고 비율 ±1%.
- **읽기**: `storage.objects` 의 읽기 정책을 **그 문집을 읽을 수 있는 사람**으로 — 우리 반 교사·학생, 모두의 아지트에 공유돼 `neighbor_book_is_readable_v1` 이 참인 사람. 그림 주소는 브라우저가 서명 주소(짧은 유효기간)로 받는다.
- **업로드 권한**: 담당 교사만, 자기 학급·문집 폴더에만(정책으로).
- **정리**: 문집 삭제·학급 삭제 때 폴더 정리. 확정판이 가리키지 않는 옛 파일은 주간 정리(30일 유예).
- 검사: `check:rpc-surface`(anon 금지), 롤백 스모크(다른 반 교사·학생 업로드/읽기 거절, 공유 해제 뒤 읽기 거절, 비율 틀린 값 거절).

## 5. 표지를 그리는 곳 — 지금 **네 곳이 따로** 그린다

| 곳 | 파일 | 할 일 |
| --- | --- | --- |
| 선생님 문집 화면·학생 서가 | `anthology/BookCover.jsx`(AnthologyManager·StudentBooks·StudentEntry) | 그림이 있으면 `<img>` 한 장 |
| 모두의 아지트 문집 도서관 | `community/neighbor-agit/books/StudentBooksPanel.jsx`·`TeacherBooksPanel.jsx` (자체 표지 마크업) | 같은 부품으로 바꾸기 |
| 인쇄 | `anthology/print.js`(자체 HTML/CSS 표지) | 첫 쪽에 그림을 꽉 채움, 인쇄 전 그림 다 불러온 뒤 인쇄 |
| 구글 문서 내보내기 | `anthology/googleDocExport.js` | 첫 쪽에 그림 넣기(서명 주소 → 그림 데이터) |

**한 곳만 고치지 않는다**: `coverSource(book)` 같은 함수 하나로 "그림 표지인지·디자인 표지인지·그림 주소"를 정하고 네 곳이 모두 그것을 쓰게 한다. 검사 하나가 네 곳이 같은 함수를 쓰는지 본다.

## 6. 만드는 순서(만들 때)

1. 마이그레이션: 버킷·정책·`cover_image` 열·동작 2개·스냅샷 + 스모크 (`npm run migrate`).
2. `coverSource` 와 그림 검사 함수(순수 함수, 단위 검사: 비율·크기·형식 경계값).
3. 표지 칸 화면(규격 표·빈 틀 내려받기·검사 문구·미리보기·되돌리기) + 실험실 `?dev-lab=` 화면.
4. 네 곳 표시 바꾸기(화면·도서관·인쇄·구글 문서), 휴대폰·태블릿 렌더 확인.
5. 도움말(교사 안내)·FEATURE_MAP·개인정보처리방침 확인(교사가 올린 그림 보관 항목 — 필요하면 7일 예고 개정).

예상: 3~4일. 만들기 전에 확인할 것: 개인정보처리방침에 "교사가 올린 표지 그림" 보관 항목을 넣을지(선생님 결정).

## 7. 받아들임 기준

- 규격 맞는 A4·A5·B5 그림은 올라가고 다섯 곳 모두 같은 그림으로 보인다.
- 비율·크기·형식·용량이 틀리면 저장되지 않고 이유가 문장으로 보인다.
- 다른 반 교사·학생, 공유되지 않은 반은 그림을 열 수 없다.
- 확정판은 발행 때 표지를 유지하고, 새 그림·되돌리기 뒤에도 바뀌지 않는다.
- 예전 문집 24권 표지는 그대로다.
