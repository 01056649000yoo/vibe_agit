# 3개 앱 통합 백업 7일 모니터링

> 목적: 새 앱별 백업 원장과 관리자 대시보드가 실제 자동 실행에서도 일주일 연속 맞는지 확인한다.
> 원문 로그·경로·비밀 값은 이 문서에 복사하지 않는다.

## 시작과 합격 기준

- 시작: 운영 반영 뒤 처음으로 오전 4시 통합 백업이 `PASS`이고 앱 결과가 3/3으로 기록된 날.
- 기간: 시작일을 1일차로 하여 7일 연속.
- 일일 합격:
  - 최신 통합 백업 `PASS`, 26시간 안쪽
  - 아지트·샘링크·자비스 앱 결과 3/3 `PASS`
  - 필수 산출물 7개, 내장·암호화 Drive·외장 SSD 모두 정상
  - 03:30 샘링크 보조 백업이 빈 덤프가 아니고 종료 오류 없음
  - `backup_failed` 운영 경고 없음
  - 아지트·샘링크·자비스 공개 진입점의 기대 HTTP 응답 유지
- 복구 합격: 기간 중 최신 복구 리허설이 40일 안쪽 `PASS`. 앱별 기록 전인 과거 리허설은
  새 스크립트로 한 번 실제 실행한 뒤 3/3 결과로 교체한다.
