# 수호룡 퀴즈 아레나 — 아지트 병합 계획 (2026-10-22 시작)

> 상태: **관리자 시험 중**(`adminOnly`, 교사 `아지트 놀이터` 메뉴의 `수호룡의 인형뽑기` 바로 아래, **개발중** 표시).
> 게임 서버는 별도 저장소 `~/suhoryong-arena`(상태는 그쪽 `docs/STATUS.md`). 이 문서는 아지트 쪽 계획이다.

## 핵심 (선생님 정리, 2026-10-22)
1. 아지트 안에서 **교사가 가볍게 퀴즈 활동을 열고 학생이 참여**한다.
2. **기본 문제는 아지트에 이미 있는 어휘·맞춤법 자료**로 만든다(교사가 아무것도 입력하지 않아도 바로 쓴다).
3. 교사가 **직접 문제를 낼 수 있고, 낸 문제 세트는 공유**할 수 있다(학년·단원 정보로 찾아 불러다 쓴다).
4. 외부 접근은 막고 **관리자 계정에서만** 개발·시험한다. 공개는 선생님이 정한다.

## 구조
- 실시간 게임은 별도 서버(Docker `suhoryong-arena`, 소켓)가 돌린다. 아지트(Supabase+Edge)에는 상시 소켓 서버를 둘 수 없다.
- 아지트가 맡는 것: **로그인·메뉴·문제 세트 저장/공유·입장권 발급**. 게임 서버는 서명된 입장권만 확인한다(아지트 DB를 읽지 않음).
- 비상구: 게임 서버의 `/host` 관리자 암호 입구는 병합 뒤에도 남긴다(아지트가 멈췄을 때·외부에서 급할 때). 이 입구는 문제 세트 공유를 쓸 수 없다.

## 이어서 할 일 (내일부터, 순서대로)
1. ~~**DB 적용**~~ **끝(2026-10-23, `20261406_quiz_arena_sets`, 스모크 통과)**.
   - 지금은 모든 RPC 가 `quiz_arena_assert_user_v1()` 한 곳으로 **관리자만** 허용한다. 공개 때 이 함수 한 곳에 `TEACHER` 를 더한다.
   - 공유 목록은 만든 사람 이름을 내보내지 않는다(`is_mine` 만). 이름 표시는 교사 동의 방식을 정한 뒤.
2. **교사 문제 만들기 화면**: 문제 직접 입력(O/X·4지선다, 한도 60/20/80자, 최대 50문제), 기본 세트에서 시작해 고치기, 저장(`save_quiz_arena_set_v1`), 내 세트 목록·삭제.
3. **공유**: `공유하기` 스위치(`set_quiz_arena_set_visibility_v1`), 공유 세트 둘러보기(학년·검색어), `내 것으로 복사해 고치기`. 학생 정보를 문제에 넣지 말라는 안내 문구, 부적절한 세트 신고·내리기 방법(관리자) 정하기.
4. **방 바로 열기**: 아지트가 입장권을 발급하는 Edge 함수(`quiz-arena-ticket`, 비밀키 `ARENA_TICKET_SECRET` 은 아지트·게임 서버가 나눠 가짐 — 위치만 문서에, 값은 안 씀) → 교사 화면에서 세트를 골라 `방 열기` → 게임 서버에 문제와 함께 방 생성(게임 서버 쪽 교사 입장권 경로 추가).
5. **학생 입장**: 학생 놀이터 카드(공개 때)·아지트 로그인 입장권으로 입장 → 다시 로그인하면 시작 뒤에도 그대로 이어하기(서버 준비 끝).
6. **AI 문제 정리**: 교사가 붙여 넣은 글 → 아지트 AI 함수(`vibe-ai`, 한도 `consume_ai_request_v1` 범위 추가)가 문제로 정리 → 미리보기에서 교사가 고치고 OK → 세트 저장. 정답은 반드시 교사가 확인.
7. **공개 준비**: `adminOnly` 제거, FEATURE_MAP·도움말·성능표(`PERFORMANCE_HARNESS.md`)·학생 도움말, 점수→포인트(`point_engine_apply`) 정책 결정, 보안 점검.

## 결정됨 (선생님, 2026-10-23)
- **공유 범위: 전체 공유**(학교 단위 구분 없음).
- **공유한 선생님 이름은 보이지 않게** — 지금 DB 는 이미 그렇게 되어 있다(`is_mine` 만 내보냄).
- **학생 점수 → 포인트는 교사가 설정**(방 열 때 켜기/끄기·점수당 포인트·하루 상한을 교사가 정함. 지급은 `point_engine_apply`, 중복 방지 `event_key`).
- **손님은 본명으로 입장**(별명 대신 이름을 쓴다). 주의: 큰 화면에 이름이 보이고, 방이 끝나면 서버 메모리에서 사라진다(저장하지 않음). 별명 필터는 이름에도 그대로 건다. 공개 전에 "손님 이름은 저장하지 않음" 안내 문구를 넣는다.

## 데이터·보안 원칙
- 문제 세트에는 학생 이름·학번·개인정보를 넣지 않는다. 기본 세트의 원본은 공개 정적 자료(`public/data/grade*_vocab.json`, `public/spelling/*`)뿐이다.
- 표는 RLS+직접 권한 닫기, 읽기·쓰기는 `SECURITY DEFINER` RPC 로만, anon 불가(SECURITY_HARNESS).
- 기본 세트 만들기는 **누를 때만** 정적 자료를 받고(`performance.load = on-open`, 홈 조회 0), 아지트 홈·학생 화면에는 아무 연결도 만들지 않는다.
- 기본 맞춤법 세트는 지금 **기본 사전+공통 카탈로그 JSON** 만 쓴다. 관리자 게시 공통 자료·학급 자료(DB)까지 쓰는 것은 4번 이후(Edge 에서 인형뽑기와 같은 방식으로).
