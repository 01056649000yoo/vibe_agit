# 열린 일 (OPEN_ITEMS)

> **아직 안 끝난 일은 여기 한 곳에만 둔다.** WORKLOG `남은 것` 에는 새 일을 풀어 쓰지 말고 ID 를 적는다(`→ OI-022`).
> 끝나면 행을 지우고, 그 일을 끝낸 WORKLOG 항목에 `OI-022 닫음` 이라 적는다. 번호는 다시 쓰지 않는다.
> `종류`: 결정(선생님이 정할 것) · 운영(맥미니·백업·설정) · 후속(코드 작업) · 실기기(로그인 화면에서 눈으로) · 관측(기다렸다 잴 것) · 제보.
> `제보` 는 내용에 **언제·기기·재현 조건** 을 꼭 적는다 — 없으면 헛짚는다(PITFALLS `증상이 "언제" 나는지부터`).
> 60행 상한, `생긴 날` 이 30일 넘은 행은 `npm run checklist` 가 짚는다. `tests/openItems.test.mjs` 가 형식을 본다.
