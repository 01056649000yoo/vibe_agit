# 맞춤법 한 달 자동 업데이트

> 2026-10-09 선생님 결정: 빨간 물결·회색 점선이 **잡지 못한 맞춤법**을 한 달에 한 번 모아 **자동으로** 반영한다.
> 장치: `scripts/spelling-monthly-update.mjs` · 맥미니 `com.agit.spelling-monthly-update`(매달 1일 05:40) · `20261387`.

## 한 달 흐름

```
한 달 동안 쌓임                                  매달 1일 05:40                              결과
─────────────────────────────────           ─────────────────────────────            ─────────────────────────
① 회색 점선에서 학생이 [이렇게 고치기]   ┐
② 회색 점선 자리를 나중에 제안대로 고침  ├→  모으기 → 관문 → 50개까지 자동 게시  →  빨간 물결(공통 자료, 🗓️ 한 달 자동)
③ 선생님이 고쳤는데 두 줄 모두 놓침     ┘                     └ 못 지난 것 → 보류 목록           텔레그램 요약
```

학생·학급 식별자와 글 원문은 남기지 않는다. 어절 조각(2~15자)·횟수·학급 수만 남긴다.

## 자동 게시 관문(모두 지나야 함)

| 관문 | 기준 | 왜 |
|---|---|---|
| 꼴 | 한글 2~15자·2어절 이하, 틀린 꼴 ≠ 바른 꼴 | 이름·부스러기 거르기 |
| 새 것 | 기본 500·검토 중 862·공통 자료에 없고, 지금 검사기가 이미 긋지 않음 | 겹치지 않게 |
| 증거 | **2개 학급 이상**, 그리고 ①은 3번 이상·받아들인 비율 80% 이상 / ②·③은 3번 이상 | 한 아이·한 반의 버릇이 아닌 것 |
| 사전 | 바른 꼴은 모두 사전(hunspell)에 있는 말 | 틀린 제안을 가르치지 않게 |
| 맞는 낱말 | 틀린 꼴이 그 자체로 맞는 낱말이면(질렸다→질렀다) **보류** | 문맥 없이 넣으면 맞는 문장(음식에 질렸다)에 밑줄 |
| 모의 실행 | 학생 글 전체에서 틀린 꼴을 품은 더 긴 낱말이 사전에 있는 바른 말이면 **보류**(본적이 ⊂ 기본적이) | 맞는 말 속 밑줄 0 |
| 상한 | 한 달 50개(증거 많은 순) | 한 번에 너무 많이 바뀌지 않게 |

설명 글은 유료 AI 없이 틀로 만든다: 띄어쓰기만 다르면 `띄어쓰기를 바르게 하면 ‘…’예요.`, 아니면 `‘…’ 대신 ‘…’라고 써요.`

## 사람이 할 일(한 달에 한 번, 5분)

1. 1일 아침 텔레그램 `🗓️ 맞춤법 한 달 업데이트` 를 본다 — 새로 더한 것 10개·보류 예·회색 점선 갈래별 받아들인 비율.
2. 이상한 것이 있으면 **관리자 › 맞춤법 승격 › 전체 공통 자료**에서 `🗓️ 한 달 자동` 표시를 찾아 적용 중지(되돌릴 수 있음).
3. 보류 가운데 넣을 만한 것(특히 `문맥이 필요` — 질렸다처럼 맞는 낱말을 잘못 고른 것)은 문맥형 자료로 손으로 넣는다.

한 달 치를 한꺼번에 끄기(맥미니):

```
docker exec -i agit-db psql -U postgres -d postgres -c "update spelling_learning_entries e set status='disabled', updated_at=now() from spelling_monthly_candidates c where c.entry_id=e.id and c.run_month='2026-10-01';"
```
