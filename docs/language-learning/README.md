# 공통 언어 학습 콘텐츠

속담·사자성어를 `오늘의 말 미션` 한 화면에만 묶지 않고, 향후 속담·사자성어의 탑과 다른 학습 활동이
같은 원본·문제·진도를 재사용하기 위한 데이터 계약이다.

## 현재 상태

- 검수용 원본: [`data/source-import-v1.json`](data/source-import-v1.json)
- 3·4학년 편집 검수팩: [`data/g34-preview-review-v1.json`](data/g34-preview-review-v1.json)
- 자동 검사: `npm run language:content:check`
- 다시 가져오기: `node scripts/audit-language-learning-content.mjs --source-dir <옛 앱의 src/data> --write`
- DB 토대: `20261160_learning_content_catalog.sql`, `20261161_learning_content_curriculum_alignment.sql`
- **아직 학생에게 제공하지 않는다.** 미리 만나기 20개는 표현·뜻·예문과 뜻 고르기를 편집 검수했지만
  `teacher_confirmation_required` 상태다. 나머지 165개는 `source_imported` 상태를 유지한다.

파일명의 `source-import-v1`은 옛 앱에서 가져온 첫 원본 묶음을 뜻한다. 내부 `schemaVersion: 3`은 그 원본에
교육과정·제공 학년 분류와 3·4학년 편집 검수팩을 합친 현재 데이터 계약 버전이다.

| 원본 | 항목 | 병합 결과 |
|---|---:|---|
| 속담 기본팩 | 85 | 표현·뜻 + 원본 초성 빈칸 문제 1종 |
| 사자성어 기본팩 3파일 | 100 | 표현·한자·뜻·예문 + 문장 완성·초성·뜻 맞히기 3종 |
| 합계 | 185 | 원본 문제 385개 + 3·4학년 뜻 고르기 20개 = 405개 |

## 학년 분류 원칙

`교육과정에 나오는 학년`과 `학생이 미리 만날 수 있는 학년`을 같은 값으로 취급하지 않는다.

- 185개 모두 교육과정 기준점은 **5·6학년군**(`curriculumBand: 'g56'`)이다.
- 속담 85개는 2022 개정 국어과 5·6학년군의 관용 표현 학습과 직접 연결하는 자료
  (`curriculumRole: 'aligned'`)로 분류한다.
- 사자성어 100개는 교육과정의 필수 목록이라고 부르지 않고, 어휘와 관용 표현 학습을 돕는 확장 자료
  (`curriculumRole: 'enrichment'`)로 분류한다.
- 실제 제공 범위인 `gradeBands`에는 모든 항목이 `g56`을 갖는다. 이 가운데 쉬운 시범 20개만
  `g34`도 함께 가져 **3·4학년 미리 만나기**에 사용할 수 있다.
- 미리 만나기는 해당 항목이 3·4학년 교육과정 내용이라는 뜻이 아니다. 3·4학년에는 뜻 고르기처럼 쉬운
  문제를, 5·6학년에는 문맥·직접 입력 문제를 연결한다.

현재 첫 직접 검수 대상으로 속담 20개와 사자성어 20개를 `core-v1` 시범팩에 골랐다. 이 중 별표 항목은
3·4학년 편집 검수까지 마친 20개이며 교사 최종 확인을 기다린다. 시범팩 밖 145개는 아직 내용 난이도를
지정하지 않았다.

속담 중 원본 `answer`에 빠진 낱말만 있던 41개는 `quiz`의 초성 자리에 답을 넣어 완성 표현 초안을
복원했다. 미리 만나기 5개는 편집 검수로 표현을 확인해 이 신호를 해결했고, 나머지 36개에는
`expression_reconstructed` 신호가 남아 있다. 58번은 원본 초성 `ㄱ ㅁ`과 답 `멍에(ㅁ ㅇ)`가 맞지 않아
`unresolved_initials`로 별도 표시했다.

### 3·4학년 편집 검수 기준

- 뜻은 국립국어원 [한국어기초사전](https://krdict.korean.go.kr/)의 표기와 핵심 뜻을 대조한 뒤 초등학생이
  이해할 수 있는 문장으로 새로 풀어 썼다. 사전 문장을 그대로 복사하지 않는다.
- 예문은 교실·과제·책·친구 관계처럼 3·4학년이 만날 수 있는 상황으로 새로 작성했다.
- 뜻 고르기는 보기 4개, 정답 1개로 고정하고 같은 문제 안에서 뜻이 겹치지 않게 확인했다.
- 국립국어원 자료에 쓰인 표준형에 맞춰 `천 리 길도 한 걸음부터`로 바로잡고, 문장 관계를 선명하게 하려고
  `콩 심은 데 콩 나고, 팥 심은 데 팥 난다`에 쉼표를 넣었다.
- 편집 검수만으로 `teacher_confirmed`나 `published`로 올리지 않는다. 교사가 20개를 최종 확인해
  `teacher_confirmation_required`를 해결하기 전에는 DB 시드와 학생 출제를 만들지 않는다.

## 한 원본, 여러 학습 경험

```text
learning_content_items          표현·뜻·한자·예문
        │
        ├─ learning_content_questions     문제 변형·서버 채점 정답
        └─ learning_content_collections   학습 묶음과 순서
                         │
                         ├─ 오늘의 말 미션
                         └─ 향후 속담·사자성어의 탑

두 경험의 답안 ──> learning_item_progress (기존 공통 학습 엔진)
```

일일 미션과 탑은 별도 항목을 만들지 않는다. 둘 다 같은
`content_type + collection_key + item_key`를 `learning_engine_record_answer_v1`에 넘긴다. 따라서 일일
미션의 첫 정답은 `familiar`, 나중에 탑에서 다른 문제 유형까지 연속 정답이면 `mastered`로 이어진다.

`collection_key`는 엔진이 해석하지 않는다. 학년군 검수를 마친 뒤 콘텐츠 쪽에서 묶음을 정하고, 일일
미션도 탑도 그 키를 그대로 사용해야 한다. 일일 미션 전용 묶음을 따로 만들면 같은 표현의 진도가 갈라지므로
금지한다.

## 항목 계약

한 항목은 다음 정보만 소유한다. 화면·포인트·하루 날짜처럼 특정 경험에만 필요한 값은 넣지 않는다.

```js
{
  itemKey: 'idiom:source-011',
  contentType: 'idiom',
  expression: '고진감래',
  hanja: '苦盡甘來',
  definition: '힘든 일이 끝난 뒤에 즐거운 일이 생긴다는 뜻이에요.',
  example: '오랫동안 연습한 끝에 좋은 결과를 얻으니 고진감래의 기쁨을 느꼈다.',
  curriculumBand: 'g56',      // 교육과정 기준 학년군
  curriculumRole: 'enrichment',
  gradeBands: ['g34', 'g56'], // 실제 제공 가능 학년군
  contentLevel: 2,            // 1~5, 문제 난이도와 별개
  themes: [],
  reviewStatus: 'editorial_review',
  reviewFlags: ['teacher_confirmation_required']
}
```

- `curriculumBand`: 교육과정상 기준 학년군이다. 현재 팩은 모두 `g56`이다.
- `curriculumRole`: `aligned`는 성취기준 직접 연결, `enrichment`는 학습을 돕는 확장 자료다.
- `gradeBands`: 실제 제공 가능 학년군이다. `g34`, `g56`만 사용하며 같은 표현을 학년군별로 복제하지 않는다.
- `contentLevel`: 표현 자체의 추상성·낯섦을 1~5로 나타낸다.
- `difficulty`: 각 문제의 풀이 난이도다. 같은 표현도 3·4학년은 뜻 고르기, 5·6학년은 문맥·직접 입력으로
  다르게 낼 수 있다.
- `reviewStatus`: `source_imported → editorial_review → teacher_confirmed → published` 순서다.
- 원본 ID는 `source.pack + source.sourceId`에 보존한다. ID가 비어 있는 구간을 새 번호로 메우지 않는다.

## 문제 유형

| 유형 | 역할 | 현재 원본 |
|---|---|---|
| `meaningChoice` | 학습 직후 뜻 확인, 일일 미션 기본 | 3·4학년 미리 만나기 20개 편집 검수 |
| `clozeInput` | 표현·문장 빈칸 직접 입력 | 속담 85, 사자성어 100 |
| `initialsInput` | 초성을 보고 표현 입력 | 사자성어 100 |
| `definitionInput` | 뜻을 보고 표현 입력 | 사자성어 100 |
| `usageChoice` | 알맞은 사용 장면 선택 | 후속 심화 문제 |

선택형 보기는 다른 항목을 기계적으로 섞어 바로 공개하지 않는다. 오답도 뜻이 겹치지 않고 문맥상 오해가
없는지 검수해야 한다. `correct_answer`와 `accepted_answers`가 든 문제표는 브라우저 직접 권한이 없으며,
학생 RPC도 제출 전에는 정답을 반환하지 않는다.

## 학생 제공 전 승격 조건

항목 한 개를 `published`로 바꾸려면 다음이 모두 필요하다.

1. 완성 표현·뜻·한자·예문의 맞춤법과 초등학생 적합성 확인
2. 교육과정 기준·역할, 실제 제공 학년군과 내용 난이도 확인
3. 최소 한 개의 검수된 `meaningChoice` 확인 문제 작성
4. 모든 `reviewFlags` 해결
5. 학습 묶음에 한 번만 배치하고 문제 난이도·허용 정답 확인

DB 제약은 학년군·난이도·미해결 신호가 남은 항목과 문제의 `published` 저장을 거부한다. 네 카탈로그 표는
익명·학생·교사 브라우저뿐 아니라 `service_role`에도 직접 권한을 주지 않는다. 후속 승격·출제는 실제 역할과
학급을 다시 확인하는 전용 `SECURITY DEFINER` RPC로만 연결한다.
