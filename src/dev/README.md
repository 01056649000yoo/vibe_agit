# 아지트 개발 실험실

`/?dev-lab=class-board`처럼 개발 서버에서만 여는 DB 없는 기능 시험 셸이다.

## 원칙

- 운영 화면의 컴포넌트를 그대로 불러오고 화면을 복사하지 않는다.
- 서버가 주는 데이터 모양과 같은 작은 fixture를 시나리오 안에서 만든다.
- 저장 동작은 시나리오 메모리 또는 `localStorage`까지만 허용한다.
- `classBoardApi`·`supabase` 같은 운영 데이터 클라이언트를 개발 시나리오에서 부르지 않는다.
- 권한·RPC·RLS·마이그레이션은 실험실 결과를 믿지 않고 `migrate:check` 롤백 스모크로 별도 확인한다.

## 시나리오 추가

1. `src/dev/` 아래에 샘플 상태를 소유하는 미리보기 컴포넌트를 만든다.
2. 실제 기능 컴포넌트를 import해서 렌더링한다.
3. `devLabRegistry.js`에 `id`·설명·지연 로딩 컴포넌트를 등록한다.
4. 빈 자료·보통 자료·긴 자료·오류 상태처럼 반복 확인할 상태를 한 화면에서 전환하게 한다.
5. 전용 회귀 검사에서 운영 API 미호출과 개발 전용 진입점 제한을 확인한다.
