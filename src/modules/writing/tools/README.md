# 글쓰기 도구 슬롯

학생 글쓰기의 저장·자동 백업·제출 흐름을 건드리지 않고 보조 도구를 붙이는 슬롯이다.

## 등록 방법

1. `tools/<tool-id>/manifest.js`에 `id`, `label`, `order`, `studentEntry`를 선언한다.
2. `tools/registry.js`에 매니페스트를 등록한다.
3. 도구는 지연 로딩되며 하나가 실패해도 글쓰기 입력창은 계속 동작한다.

## 교사 ON/OFF 연결

- 매니페스트의 `id`를 `classes.writing_editor_settings.enabled_tools`에 넣으면 해당 학급 학생에게 보인다.
- 교사 설정 화면은 `editor-settings/settings.js`의 공용 함수를 사용해 목록을 바꾼다. 기존 JSON의 다른 키는 보존한다.
- 도구 버튼만 숨기지 말고, 도구가 입력창에 붙이는 밑줄·도움말 같은 부가 표시도 같은 설정을 따라야 한다.
- 설정이 없거나 읽기에 실패하면 기존 학급의 기능이 갑자기 사라지지 않도록 기본 도구는 켠다.
- 교사 미리보기는 `WritingEditorSettingsProvider`의 `overrideSettings`로 아직 저장하지 않은 설정을 시험한다.

## 도구 계약

- 제목·본문을 검사해야 한다면 기기 안의 확정 규칙만 사용하고 외부 서비스로 자동 전송하지 않는다.
- 외부 조회가 필요하다면 학생이 명시적으로 선택하거나 검색창에 입력한 값만 사용한다.
- 학생 글을 자동으로 변경하지 않는다.
- 본문 삽입은 학생이 결과별 "넣기" 버튼을 눌렀을 때만 `onInsertText`로 요청한다. 구조화 장르처럼
  공용 본문과 동기화할 수 없는 화면에서는 삽입 버튼 대신 복사만 제공한다.
- 저장·제출·임시 저장 상태를 직접 소유하지 않는다.
- 태블릿에서 44px 이상의 터치 영역과 세로/가로 화면을 모두 지원한다.
- 외부 서비스 키는 브라우저에 두지 않는다.

`spelling-lookup`은 이 계약의 첫 구현으로, 수첩 규칙을 사용해 기기 안에서 제목·본문의 명확한 오류 후보에 밑줄을 긋고
학생이 검색창에 직접 적은 낱말·문장을 조회한다. 문장은 로컬 수첩에서만 확인하고, 학생이 찾기 버튼을 누른 낱말·짧은 구는
학생 인증을 확인하는 `korean-dictionary-search` 서버 함수를 거쳐 국립국어원 표준국어대사전 결과를 수첩 안에 표시한다.
공식 인증 키는 서버에만 두며 공용 AI를 호출하거나 본문에 변경을 적용하지 않는다.

`lab-results`는 기본 OFF이며, 교사가 학급 글쓰기 설정에서 켠 경우에만 보인다. 학생이 도구를 연 순간
`get_my_lab_results_v1`을 한 번 호출해 최근 20개를 읽고, 더 보기는 안정적인 커서로만 이어 간다.
학생 홈 조회·폴링·Realtime은 사용하지 않는다.
