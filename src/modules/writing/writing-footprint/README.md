# 글쓰기 발자국

과제·독서록·일기의 완료 기록, 포인트 활동, 작가·소통·기록가·독서가 성장을 학생·교사 화면에 보여 주는 집계 모듈이다.
목록과 개수는 같은 서버 집계 경로를 사용하며, 학급 조회는 직접 `class_id` 제한과 반환 상한을 지킨다.

- 과제 완료일은 교사 `approved_at`, 독서록·일기는 초안과 분리된 완료본 `created_at`을 사용한다.
- 친구 교류는 자기 글을 제외한 승인 댓글·현재 반응의 실제 이벤트 수다.
- 포인트는 전체 흐름을 유지하면서 활동 획득·교사 조정·시작 보너스를 서버에서 구분한다.
- 학생 화면은 순위나 학급 평균 없이 완성 글·글 종류·꾸준함·이번 학년도 수정 학습·최근 30일 변화만 보여 준다.
- 학생 상세는 화면을 열 때 `get_my_writing_footprint_detail()`로 한 번에 읽으며 폴링·Realtime을 만들지 않는다.

`manifest.js`가 나의 아지트 및 교사 대시보드 카드 기여분을 등록한다. 새 카드가 필요하면 대시보드 코어에
하드코딩하지 말고 매니페스트의 `dashboardCards`로 연결한다.
