# 맞춤법 배움 데이터 모듈

공통 수첩과 300개 기반 랜덤 5문제, 학급별 승인 항목, 학생의 명시적 검색 집계, 학급 발자국 카드를 소유한다.

- 공통 수첩의 기본 자료는 사전형 200개와 100문제에서 만든 문장형 100개를 합친 300개다.
- 교사 진입은 `manifest.settingsEntry`로 통합 설정에 지연 등록한다. 수업 도구에는 노출하지 않는다.
- 설정 메뉴는 공통 확장 슬롯 규격(데스크톱 270px, 항목 좌우 15px, 최소 높이 68px)을 그대로 사용한다.
- 학생 입력 중에는 DB에 쓰지 않는다. 수첩 검색을 메모리에서 항목별로 합친 뒤 닫을 때 RPC 한 번으로 저장한다.
- 학생 글·문장 원문은 저장하지 않는다. 검증된 항목은 ID만, 미등록 후보는 80자 이하 검색 표현만 저장한다.
- 기본 자료 300개는 모두 글쓰기 밑줄 규칙을 가진다. 명백한 오기는 바로 찾고, 둘 다 가능한 표현은 주변 문맥이 맞을 때만 찾는다.
- 기본 자료는 항목 ID·학습 라벨·큰 분류·검사 표현을 분리한다. 학습 라벨은 교사 검색과 학생 오답 묶음에 쓰고, 검사 표현 색인은 글에서 실제로 등장한 라벨 후보만 고른다.
- 기본·학급 검사는 여러 검사 표현을 한 번에 찾는 공용 후보 색인을 쓴다. 후보가 된 규칙만 문맥을 확인하되 기존 규칙 순서와 비중첩 위치·최대 50개 결과 계약은 유지한다.
- 300개 본문·규칙은 글쓰기 화면의 첫 렌더를 막지 않고 별도 청크로 한 번 내려받으며, 본문 검사는 입력을 멈춘 뒤 350ms 후 실행한다.
- 퀴즈는 기본 자료 300개 전체에서 수첩을 열 때마다 중복 없는 5문제만 무작위로 뽑는다. 풀이 진행과 점수는 서버에 저장하지 않는다.
- 학급 항목은 AI 초안 뒤 교사가 승인해야 학생 검색과 밑줄에 반영된다.
- 학급 발자국 카드는 `manifest.dashboardCards`로 등록하며 대시보드 본체에 기능 전용 카드를 하드코딩하지 않는다.
- 공통 데이터 승격은 후속 관리자 검수 흐름에서 다룬다. 학급 항목을 자동으로 공통 공개하지 않는다.
