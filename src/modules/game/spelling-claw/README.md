# 맞춤법 인형뽑기 (spelling-claw) — 1단계 시제품

맞춤법 퀴즈를 풀어 코인을 얻고, 코인으로 3D 인형뽑기를 해 상품을 받는 놀이터 모듈이다.
지금은 **실험실(`?dev-lab=spelling-claw`)에서만** 돈다. 놀이터 레지스트리에 등록하지 않았고 운영 빌드에 들어가지 않는다.

## 선생님 결정 (2026-10-01)
- 맞춤법 10문제 중 **교사가 정한 개수 이상** 맞히면 코인 1개. 하루 기회(코인) 수도 교사가 정한다.
- 집기에 실패해도, 하루 기회를 다 쓰고 하나도 못 뽑았으면 **교사가 정한 최소 포인트**를 준다(문제를 풀었으니).
- 수호룡 아이템은 **학생이 지금 단계에서 상점에서 살 수 있는 것만**. 전설(만렙 선물)·업적·무료·가진 것은 빠진다. 예외 없음.
- 코인은 공부로만 얻는다 — 포인트로 코인을 사는 길은 만들지 않는다. 꽝 없음, 확률 공개.

## 파일
- `engine/clawEngine.js` — 원본 `10만들기_인형뽑기.html` 의 기계·집게·인형 물리(three.js 0.170 + Rapier 0.14)를 옮긴 것.
  화면과 맞닿는 부분만 바꿨다(코인·문제·도감은 밖으로, `emit` 으로 알림). 물리 수치는 원본 그대로.
- `ClawMachineStage.jsx` — 엔진을 **열 때만** 불러오는 화면. 코인은 `onSpendCoin` 이 참일 때만 한 판을 시작한다.
- `plushCatalog.js` — 동물 인형 8종(`public/assets/claw/plush/*.glb`). 포켓몬은 저작권 때문에 넣지 않는다.
  동물 모델은 Tripo AI 로 만들었다 — 정식 공개 전 생성 당시 요금제의 이용 조건(공개 서비스 사용 가능 여부)을 확인한다.
- `quiz/spellingQuizBuilder.js` — 퀴즈 만들기·채점의 **하나뿐인 원본**. 사전 항목에서 그때그때 문제를 만든다
  (기본 500 + 관리자가 게시한 공통 자료 + 우리 반 학급 자료 → 게시하면 다음 퀴즈부터 저절로 출제, 적용 중지하면 빠짐).
  유형: 고르기·빈칸 고르기(객관식), 고쳐 쓰기·띄어 쓰기(주관식). 빈칸 쓰기는 정답이 하나로 안 정해져 뺐다.
  난이도 쉬움/보통/어려움 = 주관식 3/4/6개. 앱 전용 import 가 없어 2단계 서버(Deno)도 같은 파일을 쓴다.
  앱 사전과 공개 파일(`public/spelling/*.json`)이 같은 문제를 만드는지 검사가 본다.
- `prizeTable.js` — 상품 설정의 **하나뿐인 원본**: 기본값(`CLAW_DEFAULT_PRIZE_SETTINGS`)·검증(`normalizeClawPrizeSettings`)·
  추첨(`rollClawPrize`)·확률 공개(`describeClawOdds`). 추첨과 확률 공개는 같은 "지금 나올 수 있는 줄" 계산을 거쳐 어긋나지 않는다.
  2단계에서 교사 설정은 학급 설정(DB)에 두고, 서버(Deno)도 이 파일로 검증·추첨한다(앱 전용 import 없음).
- `ClawTestBench.jsx` — 탭 두 개: `🛠️ 교사 관리`(학급 설정·상품 설정을 펼쳐 둠) / `🧒 학생 화면`(학생이 보는 그대로, 탭을 오가도 상태 유지).
- `ClawPrizeSettings.jsx` — 교사 상품 설정 판(2026-10-02): 종류·포인트 금액·선생님 선물 목록·아이템 등급 비중, 칸마다 실제 확률.
  1단계는 시험대가 이 브라우저(`spelling-claw-prize-settings-v1`)에만 저장한다.

## 학생 홈 알림 (2026-10-02 결정)
- 하루 기회를 다 쓰고 하나도 못 뽑아 **최소 포인트를 받으면** 학생 홈 활동 알림으로 알린다(`spelling-claw.consolation_awarded`,
  표시는 `manifest.notifications`). 2단계 서버가 포인트를 줄 때 같은 트랜잭션에서 `notification_emit_v1` 을 부르고,
  `event_key` 는 학생·날짜로 정해 하루 한 번만 남긴다. 폴링·Realtime 은 더하지 않는다(`modules/notifications/README.md`).
