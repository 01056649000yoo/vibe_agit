# 수업 도구 모듈 추가 계약

쌤링크처럼 교사가 수업 중 사용하는 앱은 `src/modules/tool/<module-id>/`에 둔다.
앱 코드를 교사 대시보드에 직접 추가하지 않고 manifest와 `teacherEntry`로 연결한다.

```js
export const sampleToolManifest = {
  id: 'sample-tool',
  name: '샘플 수업 도구',
  description: '수업에서 사용하는 도구',
  icon: '🧰',
  part: 'tool',
  audience: 'teacher',
  teacherEntry: () => import('./TeacherEntry'),
  tool: {
    order: 10,
    launchMode: 'embedded'
  }
};
```

`src/modules/registry.js`에 manifest를 등록하면 교사 `수업 도구` 런처에 자동으로 표시된다.
선택하기 전에는 앱 코드를 로드하지 않는다. 외부 앱은 인증·데이터 계약을 먼저 정한 뒤 연결하며,
비밀 값이나 외부 앱 코드를 아지트 코어 셸에 직접 섞지 않는다.

## 현재 도구

- `class-board`: `우리 반 스크린`. 보드 셸은 위젯 목록·배치·저장·스크린 표시만 맡고, 텍스트·이미지·글쓰기 현황은
  `widgets/registry.js`에 등록된 독립 위젯이 소유한다. 왼쪽 자료의 위치·크기·핀 상태는 보드에 저장하며, 오른쪽
  현황은 담당 교사에게 현재 미션 이름표와 오늘의 일기·독서록 숫자만 전달하고 글 내용·내부 ID는 제외한다.
  스크린의 `화면 편집`도 같은 위젯 레지스트리·설정·배치 엔진을 재사용한다. 변경은 임시 보드에서 처리한 뒤
  교사가 저장하거나 취소하며, 오른쪽 현황은 편집할 수 없는 읽기 전용 영역으로 유지한다. 현황은 화면별 데이터가
  아니라 수업 중 즉시 접고 펼치는 표시 상태이며, 접으면 위젯을 내려 갱신을 쉬고 콘텐츠 캔버스가 전체 폭을 쓴다. 이미지 업로드가 끝나면 실제
  이미지 비율과 현재 콘텐츠 캔버스 크기로 위젯을 한 번 자동 맞추고, 이후 수동 크기 조절은 비율 제한 없이 허용한다.
  편집 중에는 이미지·텍스트 본체와 상단 이동 손잡이를 모두 드래그 표면으로 사용하며, 핀을 꽂으면 이동·크기
  변경을 함께 잠근다. 캡처 이미지는 편집 화면에서 `Ctrl+V`로 붙여넣을 수 있다. 선택 이미지 → 빈 이미지 칸 →
  새 이미지 칸 순서로 대상을 정하고, 파일 업로드와 같은 1920px·1MB 최적화·비공개 Storage 경로를 거쳐 실제
  비율로 한 번 맞춘다. 저장된 스크린은 최대 20개 상단 탭으로 전환한다. `새 탭`에서 이름과 내용을 정하고
  `현재 탭 저장`을 누르면 상단에 추가되며, `탭에서 숨기기`는 기존 archive 경계로 목록에서 제외한다. 숨긴 목록은
  교사가 명시적으로 `숨긴 탭 복구`를 열 때만 읽고 담당 학급 화면만 활성 탭으로 되돌린다. 날씨는 위치·외부 API 없는 수동 카드,
  타이머·스톱워치는 브라우저 로컬 실행, 학생 무작위 뽑기는 담당 학급 이름 최대 100명을 한 번 읽는 위젯이다.
- `meal-board`: `얘들아, 밥 먹자!` 급식·학생별 비고 확인. 첫 화면으로 열리며, 나이스 키는 서버 함수만 읽고, 공개
  전체화면에는 학생 이름과 비고를 전달하지 않는다. 비고는 선택 사항이며 담당 학급 RPC로만 읽고 쓴다.
- `classroom-arrangement`: 자리·역할 배치
- `samlink`: URL 단축하기(쌤링크). 필요한 경우 선택할 때만 외부 페이지를 지연 로드한다.

## 우리 반 스크린 위젯 계약

새 표시 기능은 `src/modules/tool/class-board/widgets/<widget-id>/`에 두고 `widgets/registry.js`에 매니페스트를
등록한다. 보드 셸에 위젯 ID 조건문을 추가하지 않는다. 매니페스트는 `id`, `version`, `projectorSafe`,
`defaultPlacement`, `createDefaultConfig`, 지연 `load`를 갖고, 설정 화면이 있으면 `loadSettings`도 선언한다.
실시간 데이터가 필요한 위젯은 자신의 요청 예산을 `requestBudget`에 적는다. 교실 표시용 학생 이름이 필요하면
담당 교사 권한·100명 상한·내부 ID와 본문 제외를 서버에서 강제한다. 보드는 위젯의 배치와 설정만 저장하며 살아
있는 현황 데이터는 저장하지 않는다.
날씨·타이머·스톱워치처럼 서버 데이터가 필요 없는 수업 위젯은 외부 API나 폴링을 붙이지 않는다. 학생 무작위
뽑기는 담당 학급 전용 RPC로 활성 학생 이름만 최대 100명 한 번 읽고, 학생 ID·인증 ID·학생 코드는 반환하거나
보드 JSON에 저장하지 않는다. 뽑기 순서와 시간 도구의 실행 상태도 메모리에만 둔다.
자유 배치 본문을 직접 옮길 위젯은 보드 셸이 전달하는 `dragHandleProps`를 표시 컴포넌트의 최상위 요소에
펼친다. 셸은 클릭과 드래그를 3px 임계값으로 구분하고, 핀 상태에서는 이 속성을 전달하지 않는다.
클립보드 이미지는 `widgets/image/useClassBoardImagePaste.js`가 편집 중에만 감지한다. 텍스트 붙여넣기는 건드리지
않고 이미지 파일이 있을 때만 기본 동작을 막으며, 업로드 중 스크린이 바뀌면 다른 보드에 잘못 연결하지 않는다.
