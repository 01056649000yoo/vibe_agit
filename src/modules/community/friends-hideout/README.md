# 친구 아지트

같은 학급 친구의 공개 글·칭호·수호룡을 보는 고정 커뮤니티 모듈이다. 학생 화면에서 항상 사용할 수 있으며
교사 ON/OFF 대상이 아니다. 친구 목록과 글 조회는 해당 테이블의 `class_id`를 직접 제한하고 상한·공용 캐시 규칙을 지킨다.

- 진입: `manifest.js`의 `studentEntry`
- 데이터 훅: `useFriendsHideout.js`
- 프로필 카드: `profile/`
- 공개 범위·댓글 상태를 우회하는 클라이언트 조회를 추가하지 않는다.

## 우리 반 새 글 피드 계약

- 1차 필터는 `전체 새 글 / 선생님 과제 / 자율 글`이다. 새 미션 장르는 선생님 과제 안에 자동 포함한다.
- 자율 글 필터는 각 글쓰기 모듈 매니페스트의 `communityFeed` 선언을 `getCommunityFeedSelfTypes()`가 모아 만든다.
  새 자율 글 유형 때문에 `FriendsHideout.jsx`에 탭·문구·아이콘 조건을 추가하지 않는다.
- 목록은 `get_class_public_writing_feed_v1` 한 번으로 글·작성자·미션·반응을 최대 10편씩 읽는다. 다음 페이지는
  공개 시각과 글 ID 커서를 쓰며, 서버 최대 상한은 50편이다. 유형마다 RPC를 복제하거나 offset 페이지를 쓰지 않는다.
- 기본 진입은 공개 글 피드만 한 번 읽는다. 과제 목록은 `선생님 과제`를 처음 열 때, 친구 명단은 `친구 아지트`를
  처음 열 때 지연 조회한다. 이미 진행 중인 같은 피드 요청은 재사용하고 화면 복귀 갱신은 실제로 한 번이라도 연
  보조 목록만 갱신한다.
- 서버는 로그인 학생의 실제 학급을 구해 `student_posts.class_id`를 직접 제한하고 제출된 `class` 공개 글만 반환한다.
  일기는 기본 비공개이며 학생이 친구 공개를 선택한 글만 피드에 나타난다.
