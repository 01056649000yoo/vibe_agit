# 이웃 아지트

여러 학급이 초대로 참여해 글을 나누는 후속 독립 모듈이다. 학급 생성·삭제를 담당하는 `ClassManager` 안에 기능 카드를 넣지 않는다.

현재는 `manifest.teacherEntry`로 교사 대시보드의 `학급운영도구` 오른쪽에 독립 Beta 메뉴를 제공한다.
설정에는 중복 진입점을 두지 않는다. 초대·호스트 승인·학생 피드·댓글·공감·간직하기는
전용 테이블/RPC를 설계한 뒤 연결한다.

준비 화면은 `constants/preparationRoadmaps.js`의 단일 원본을 사용해 교사 연결 → 글 확인 → 학생 이웃 글
피드 → 학급별 사용 관리의 예정 흐름만 안내한다. 아직 동작하는 버튼이나 데이터 요청은 만들지 않는다.

제품 범위·최대 네 학급·호스트/게스트 권한·원본 글 보존·전용 RPC·관리자 내부 공개와 이번 주 구현 순서는
루트의 [`NEIGHBOR_AGIT_PLAN.md`](../../../../NEIGHBOR_AGIT_PLAN.md)를 정본으로 사용한다.
