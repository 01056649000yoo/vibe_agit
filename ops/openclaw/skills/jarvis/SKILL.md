# 자비스 통합 명령

모든 일은 **한 가지 모양**의 명령으로 한다. 실행 정책 때문에 절대 경로 그대로 쓰고 `cd`·`&&`·`python3 -c`·상대 경로·`rg`·`awk` 는 쓰지 않는다.

`J` = `/usr/bin/python3 -B /Users/seunghyeonmaegmini/Jarvis_Brain_Local/scripts/jarvis.py`

| 요청 | 명령 |
|---|---|
| 업무 추가·완료 | `J task add --title "내용" [--date YYYY-MM-DD] [--done]` · `J task done --match "키워드"` |
| 학사일정 | `J calendar add --title "이름" --start D [--end D] [--start-time HH:MM --end-time HH:MM] [--category 분류] [--note 메모]` |
| 프로젝트 기록 | `J project update --name "프로젝트" --text "내용" [--date D]` (처음 만들 때만 `--create`) |
| 메모 | `J memo add --title "제목" --body "본문" [--tags a,b] [--pinned]` |
| 시간표 | `J timetable set --date D --subjects 1교시 2교시 ...` (바꾸지 않을 교시는 `-`) |
| 학급기록 | `J journal add --student "이름[,이름]" --text "내용" [--date D] [--category 생활지도]` — **구글로 보내지 않는다** |
| 첨부파일 | `J attach add --file <받은 파일 경로> --to <붙일 문서 예: Memos/2026-10-13_x.md>` |
| PDF | `J pdf find "키워드"`(정리본 먼저) · `J pdf read --id N [--grep 키워드] [--max 4000]` |
| 엑셀 | `J excel read --file <받은 xlsx> [--sheet S]` → 채울 값을 정해 → `J excel fill --file <받은 xlsx> --set "시트!B3=값" ...` → 답에 `MEDIA:<출력 경로>` 한 줄로 파일을 돌려준다 |
| 구글 시트(표 저장) | `J sheet fill --title "제목" [--tab 탭] --header "열1\|열2" --row "값\|값" ...` |
| 구글 시트(빈 양식) | `J sheet create --title "제목" --tab "탭" --column "열" ...` (공개 권한은 사용자가 말했을 때만) |
| 구글 문서(글 저장) | `J doc create --title "제목" --body "마크다운 본문"` (제목 `#`, 목록 `-`, 표 `\|`) |
| 삭제·복구 | `J remove --kind task\|memo\|cal\|proj --match "키워드"`(휴지통으로 이동) · `J restore --list` · `J restore --id <번호>` |

## 문장으로 맡긴 복잡한 일
짧은 명령으로 안 되는 일(여러 자료를 모아 정리, 비교, 보고서 초안, 조건이 붙은 요청 등)은 지금처럼 **문장 그대로** 풀되, 자료를 찾을 때는 위 명령과 DB 조회(`docker exec agit-db psql ...` 한 번)를 쓴다.
- **결과 자동 저장**: 요청에 "정리·표·보고서·요약·비교·분석·초안·계획서·안내문" 같은 말이 있거나 자료를 여러 개 모아 만든 결과면, 답을 끝낸 뒤 **크기와 상관없이 스스로 저장**한다. 표 모양이면 `sheet fill`, 글 모양이면 `doc create`. 둘 다 **나만 보기**로 만들어지고, 답 끝에 `저장: <링크>` 한 줄만 덧붙인다. 사용자가 "저장하지 마"라고 하거나 한 줄 답(조회·확인)이면 저장하지 않는다.
- **보내면 안 되는 것**: 학급기록·학생 상담·보안저장소·보호된 PDF 내용, 학생 이름이 들어간 개인 기록, 주민등록번호·비밀번호는 구글 문서·시트에 넣지 않는다. 이런 자료가 섞이면 개인정보를 뺀 요약만 저장하거나, 저장하지 않고 이유를 한 줄로 말한다. (스크립트도 주민등록번호 모양은 거절한다.)
- 공개 링크로 바꾸는 일은 사용자가 `링크 보기/편집` 을 분명히 말했을 때만 한다.

## 규칙
- 명령은 **한 번만** 실행하고 출력 한 줄을 그대로 보고한다. 재확인 조회를 하지 않는다.
- 날짜는 "9/3", "다음 주 월요일" 같은 말을 오늘 기준 `YYYY-MM-DD` 로 바꿔서 준다.
- 종료 코드 2("이미 있습니다", "여러 건", "프로젝트가 없습니다")는 실패가 아니라 확인이 필요한 것이다. 출력 그대로 알리고 멈춘다. 새 프로젝트를 만들라고 했을 때만 `--create`.
- 막히거나 오류(종료 코드 1)면 다른 방법을 시도하지 말고 **출력 한 줄만 보고하고 멈춘다**.
- 삭제는 사용자가 분명히 지우라고 했을 때만. 휴지통으로 가므로 되살릴 수 있다고 알린다.
